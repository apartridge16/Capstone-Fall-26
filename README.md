# Adaptive Strength Progression App

A mobile strength-training app designed to help users improve their 1RM on a selected lift.

The app collects workout performance and pre-workout check-in data such as sleep, fatigue, soreness, stress, nutrition, and motivation. This data will be used with statistical and machine-learning models to predict performance and eventually provide personalized training recommendations.
